# Actividad 9 | Escalamiento responsable de SentimentAI Banking

El caso estudia un clasificador de comentarios bancarios y compara alternativas para escalarlo en un entorno de nube simulado. La recomendación es usar réplicas en dos zonas durante un piloto controlado, condicionado a pruebas de capacidad, calidad y gobernanza.
